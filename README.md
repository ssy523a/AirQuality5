# AirQuality5

AirQuality5 is a lightweight native macOS application that provides a clear and intuitive 5-day air quality forecast.

The app can automatically detect your current location or let you search for a city manually. It retrieves forecast data from the Open-Meteo Air Quality API and presents US AQI, PM2.5, and PM10 information in an easy-to-read macOS interface.

Each day can be selected to open a detailed hourly view, allowing you to see how air quality is expected to change throughout the day. PM2.5 and PM10 are displayed separately with color-coded air quality ranges for better readability.

### Features

- 5-day air quality forecast
- Automatic current-location detection
- Manual city search
- US AQI, PM2.5, and PM10 information
- Separate PM2.5 and PM10 trend charts
- Hourly forecast for each selected day
- Color-coded air quality ranges
- Interactive Swift Charts
- Light and Dark Mode support
- Native macOS interface
- Built with SwiftUI and Core Location
- No third-party frameworks required

### Data Source

Air quality forecast data is provided by the Open-Meteo Air Quality API.
